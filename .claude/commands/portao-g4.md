## Passo 3 — Tabela das oito lacunas

No dossiê, uma linha por capacidade F1 a F8, com três colunas: **resolvida /
parcialmente resolvida / não resolvida**, a **evidência** que sustenta a
classificação, e a **recomendação** correspondente — escalar, iterar ou parar.

funciona tecnicamente mas não produz evidência decisória falhou em seu
propósito, ainda que todo o código esteja correto. Se a evidência para uma
lacuna for fraca, diga que é fraca.
