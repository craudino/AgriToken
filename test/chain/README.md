# test/chain — diretório de A1

Vazio na Fase 0 por decisão: o briefing proíbe escrever implementação antes de
G1. O que existe aqui é o alvo.

Ao iniciar W1, A1 implementa os dez invariantes de
`docs/contracts/abi/README.md` como testes de propriedade em Foundry, antes da
implementação dos contratos. Um invariante que não falha contra uma
implementação vazia não está testando nada — comece vendo cada um falhar.
